# Source and licence scope

Included: the owner-authored named-base and diamond connector builders, a Microsoft TRELLIS image-to-mesh adapter, a one-command orchestrator, Blender inspection/render gates, and **one** modified OFL font with its licence. The code is MIT; the font is SIL OFL 1.1. Model weights and TRELLIS dependencies are obtained separately from their official project.

Excluded: the private production repository, customer records, proprietary or personal-use fonts, model weights, keys, printer controls, third-party photos and the generated STL catalogue. This workflow produces candidate top and base STLs without hand-modelling, but no full model run or physical print was executed for this revision. Source availability does not confer a physical-fit or universal-printer guarantee.

The adapted `build_base_named.py`, `connector_std.py` and `weld_plug.py` modules come from Wallace's own `datarockmonkey/3d-award-business` repository; its relevant source history includes commit `4b609a5` authored by Wallace. The owner requested this public code release. The generated neutral geometry control is test data, not an award design.
