# Source scope

Included: the owner-authored portable named-base builder, unchanged connector constants, a reviewed top connector script, and independent Blender inspection/render controls. The top script was adapted from the private production repository: decimation now defaults off, disconnected-island export is refused, and STL millimetre export was fixed by a written-file check. This snapshot makes the public workflow understandable, but the top script still requires human mesh decisions.

Excluded: the private production repository's customer records, proprietary or personal-use fonts, model weights, keys, internal infrastructure, printer controls, third-party photos and generated STL catalogue. TRELLIS and other image-to-3D tools must be obtained under their own licences. This is not a full mirror of every historical production script and does not claim to reproduce all historical awards. No physical fit or universal printer guarantee is conferred by source availability.

The adapted `build_base_named.py`, `connector_std.py` and `weld_plug.py` modules come from Wallace's own `datarockmonkey/3d-award-business` repository; its relevant source history includes commit `4b609a5` authored by Wallace. The owner requested this public code release. The generated neutral geometry control is test data, not an award design.
