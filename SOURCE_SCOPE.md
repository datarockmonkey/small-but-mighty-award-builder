# Source and licence scope

Included: the owner-authored named-base and diamond connector builders, a Microsoft TRELLIS image-to-mesh adapter, a one-command orchestrator, Blender inspection/render gates, **one** modified OFL font with its licence, and the owner's [standalone mascot icon](assets/sbm-mascot.png). The code is MIT; the font is SIL OFL 1.1. The mascot remains Small But Mighty brand artwork and is not covered by the code or font licence. Model weights and TRELLIS dependencies are obtained separately from their official project.

Excluded: the private production repository, customer records, proprietary or personal-use fonts, model weights, keys, printer controls, third-party photos and the generated STL catalogue. This workflow produces candidate top and base STLs without hand-modelling. One full model-to-STL run has passed from a fresh clone, but no physical print was executed. Source availability does not confer a physical-fit or universal-printer guarantee.

The adapted `build_base_named.py`, `connector_std.py` and `weld_plug.py` modules come from Wallace's own `datarockmonkey/3d-award-business` repository; its relevant source history includes commit `4b609a5` authored by Wallace. The owner requested this public code release. The generated neutral geometry control is test data, not an award design.
